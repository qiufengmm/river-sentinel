## 3. 冻结设计决策（HS-D-1 ~ HS-D-15）

- **HS-D-1 时域定义**：未来 1/3/6 **步**；网格为 1 小时，故等价于 1/3/6 小时。沿用既有 `DEFAULT_HORIZONS=(1,3,6)` 与 `prediction_h{h}` 列名，**不引入** `prediction_d{k}` / `lead_days`。
- **HS-D-2 主目标**：小时网格水位值 `water_level_m`（桶左沿时刻 `observed_at`）。
- **HS-D-3 多时域策略**：直接多时域（与既有 `persistence_forecast` 一致），**禁止递归滚动**。
- **HS-D-4 基线口径**：持久性基线 anchor = 当前小时水位值；三个 horizon 各自报告，不递归。
- **HS-D-5 桶语义与有界前瞻（必须写进论文）**：`resample_water_level` 桶内取**末次观测**，行 `t` 可能包含 `t` 之后最多 1 个桶宽（1 小时）内的读数。因此 **1 小时 horizon 的评估结果偏乐观**，3/6 小时不受影响。论文与报告必须显式声明该有界前瞻，不得把它描述为严格因果序列。
- **HS-D-6 缺失与插补（阈值待定）**：`max_interpolation_steps` **不得拍脑袋取值**。既有默认 `DEFAULT_STEPS=2`；DS-2b 必须给出连续空缺段长度分布与 `{0,1,2,3,6}` 的敏感性表（插补行数、缺失率、各 horizon 可用样本量），由主 Agent 依据实测分布裁定后写入配置。空缺超过阈值的桶保持 `NaN`，**不参与训练与评估**，不得用全段统计量填充。
- **HS-D-7 切分**：按时间顺序 0.70 / 0.15 / 0.15，不 shuffle，段间不重叠；特征窗口与标签**不得跨段**。
- **HS-D-8 泄漏约束（硬）**：允许使用历史水位滞后（1/2/3/6/12/24 步等）、截至当前时刻的历史降雨、前 1/3/6/12/24 小时累计降雨、时钟与月份特征（**汛期标志仍不启用**，无官方口径依据）。**禁止**：未来时刻降雨、未来水位、全数据集归一化/插补统计量、测试期参与特征或超参选择、事后修订数据。
- **HS-D-9 降雨对齐与代理变量性质**：DS-3 数据为 **Open-Meteo Best Match 网格化再分析降雨**（实测 `models=era5_land` 在本区域全空；2020 年 WC-G1：Best Match 1341.5 mm vs `models=era5` 1186.8 mm）。5 个网格点区域平均为「**文成县区域降雨代理变量**」，**不是地面雨量站实测值**；论文与页面不得写 ERA5-Land 或实测站。
- **HS-D-10 指标**：三个 horizon 分别报告 MAE、RMSE、R²、NSE；高水位事件报告 Precision、Recall、F1、提前量。**无官方警戒水位时只能用训练集分位数定义「研究性高水位事件」**，并显著标注其不是官方预警标准。
- **HS-D-11 模型与实验（后续阶段）**：至少比较 ① 持久性 ② 统计/线性 ③ XGBoost 或 LightGBM ④ LSTM 或 TCN；至少两组实验：**仅历史水位**、**历史水位 + 网格化再分析降雨**。模型模块需新建（当前不存在）。
- **HS-D-12 结论保守性（硬）**：可用样本量约 2,026 小时（DS-1b 回执口径；DS-2b 须复算），测试段约 300 小时量级。所有结论一律标注**探索性/教学科研**，**不得**给出正式洪水预警结论，**不得**就高水位事件下确定性结论。
- **HS-D-13 数据治理沿用**：重复时间戳取末次并计数；`NaN`/`±inf` 排除并计数；异常值**只标记不删除**，阈值由**训练集**分位数拟合；原始文件落 `data/raw/` 即不可变（SHA-256 登记）；展示一律标注「历史数据 / 历史回放」。
- **HS-D-14 MS 计划处置**：MS-4「小时对齐」与主线的语义冲突**已解除**（同为小时尺度）；但 MS-2（站身份）与 MS-3（需凭据数据源）前置条件仍未满足 → **MS-2/3/4 继续暂停**，保留三棵工作树与三份提示词，不清理、不删除；待小时主线闭环后按本方案重写。
- **HS-D-15 停止条件**：① 有效小时样本 < 1,500 或测试段有效小时 < 200 → 停止建模并报告数据不足；② 既有 216 项测试数量下降或断言被修改 → 停止合并；③ 发现测试期信息参与特征/超参选择 → 整体返工；④ 出现把 Best Match 再分析降雨称为实测站或预报 → 文案返工；⑤ 官方警戒水位未获得时给出「超警」结论 → 降级为研究性表述。

小时尺度专项验收：

1. 小时桶手算核对：指定桶取**末次**观测，桶左沿为 `observed_at`；
2. 跨桶边界：10:59:30 与 11:00:30 归属相邻两个桶；
3. 连续空缺段长度分布与插补敏感性表（HS-D-6）随回执交付；
4. **泄漏探针**：把未来时刻降雨列整体置 NaN，特征矩阵与预测结果不得改变；
5. 切分严格时序、不重不漏、不 shuffle，窗口不跨段；
6. 归一化/插补统计量仅在训练集拟合（探针：改变测试集取值，训练集拟合结果不变）；
7. 产物确定性：同一输入两次运行逐字节一致；严格 JSON 可解析，非有限值写 `null`。

## 7. 风险与遗留

1. **样本量是最大约束**：约 2,026 有效小时、118 天，深度学习易过拟合，需早停与严格验证集，结论必须保守（HS-D-12）；
2. **有界前瞻**（HS-D-5）使 1 小时结果偏乐观，必须在论文局限性中声明；
3. 连续空缺 1,064 小时的分布尚未量化，插补阈值待 DS-2b 实测后裁定；
4. DS-3 数据为 Best Match，与 `era5` 差异约 13%，是再分析网格数据，与地面站存在系统性偏差，须写入局限性；
5. DS-3 的两项 P0（参数名 `model` vs `models`、ERA5-Land 口径）须由 DS-3b 修复后才能用于正式实验；
6. 目标断面坐标未核实，降雨为县域区域代理变量，断面代表性有限；
7. `data/samples/` 下暂无样例文件，DS-2b 需自带最小合成样例用于测试（真实数据不进 Git）；
8. 毕业材料目录（阶段 5）仍未建立，时间敏感。
