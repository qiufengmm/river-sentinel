# 小时尺度水位预测模型实验（DS-6）

本文件记录 DS-6（模型模块）的**完整实验设计与结果**，输入为 DS-4b 冻结的特征矩阵，对照
口径为 DS-5b 实测的持久性基线。全部数字可由同目录下的机器可读产物
`data/processed/hourly_model_experiments.json` 复算得到（该 JSON 被 `.gitignore` 忽略，
仅本文件进入提交）。

**使用声明**：本数据集、本模型与本文一切结论仅用于教学、科研与辅助分析，不替代水行政主管
部门的正式监测、预警、调度或应急决策，不得冒充官方发布预警。

## 1. 实验设计

### 1.1 两组特征集

| 实验 | 特征列 | 列数 |
| --- | --- | --- |
| **E1 仅水位** | `water_level_t`、`water_level_lag_{1,2,3,6,12,24}`、`hour_of_day`、`month` | **9** |
| **E2 水位 + 降雨** | E1 的 9 列 + `rain_lag_{0,1,2,3,6,12}`（6）+ `rain_cum_{1,3,6,12,24}`（5） | **20** |

E2 的 20 列与 `river_sentinel_ml.features.feature_columns()` 的返回顺序**逐字一致**，已由
`ml/tests/models/test_models.py::test_e2_subset_matches_feature_columns_order` 固化。
两组都**不启用**汛期标志（无官方口径依据，HS-D-8）。特征子集由
`river_sentinel_ml.models.training.select_features` 强制校验，缺列直接 `ValueError`，不做静默降级。

### 1.2 四类模型

| # | 模型 | 实现 | 关键超参 | 缺失特征处理 |
| --- | --- | --- | --- | --- |
| 1 | **持久性基线** | 直接引用 DS-5b 实测值，**不重训** | anchor = 当前小时水位 | 不适用 |
| 2 | **Ridge 线性** | `sklearn.linear_model.Ridge(solver="cholesky")` + 训练段 z-score | `alpha ∈ {0.1, 1, 10, 100}` 在 validation 上按 MAE 选优 | 剔除含 `NaN` 的行并计数 |
| 3 | **XGBoost** | `XGBRegressor`，`objective=reg:squarederror` | `n_estimators≤2000`、`learning_rate=0.05`、`max_depth=4`、`subsample=0.9`、`colsample_bytree=0.9`、`min_child_weight=1.0`、`reg_lambda=1.0`、`early_stopping_rounds=50`、`tree_method="hist"`、`n_jobs=1`、`device="cpu"` | **原生处理**（`missing=NaN`），不剔除任何行 |
| 4 | **LSTM**（torch） | 单层 `nn.LSTM(hidden_size=32)` + `nn.Linear(32,1)`；输入形状 `(batch, 1, features)`，**每行一个时间步** | `epochs≤300`、`patience=20`、`batch_size=64`、`Adam(lr=0.01)`、`torch.manual_seed(seed)`、`torch.use_deterministic_algorithms(True)`、**CPU 训练** | 剔除含 `NaN` 的行并计数 |
| 5 | TCN（可选） | **本轮未实现** | — | — |

关于 TCN：DS-6 提示词将其列为可选。本轮 `epochs≤300` 的 LSTM 已能在 39 秒内跑完
2×3×3×3 = 54 次训练，TCN 亦可在同一协议下补做；但 test 段有效样本只有 144 / 118 / 84，
再加一个容量更大的深度模型不会改变"样本量是瓶颈"的结论，故本轮**不做**，如实记录为未实现。

### 1.3 训练与评估协议（逐条落实）

| 协议要求 | 落实位置 | 证据 |
| --- | --- | --- |
| 只允许 train 段拟合 | `models/splitting.py::Standardizer`（只接受传入矩阵）、`models/linear.py::select_alpha`、`models/gbdt.py` / `models/sequence.py` 的 `eval_set` / 早停监控 | 测试 `test_standardizer_and_coefficients_are_untouched_by_the_test_segment` |
| test 段只在最终评估时使用一次 | `models/training.py::_run_one` 只在拟合完成后读 `segments["test"]` | 同上 + `test_train_predictions_survive_a_rewritten_test_segment` |
| 只用 `usable_h{h} == True` 的行（C-5） | `models/splitting.py::build_segment_samples` | `test_segment_sample_counts_match_usable_flags` |
| 禁止跨段窗口 | 特征由 DS-4b 段内构造，模型侧只做切片 | DS-4b 冻结的 5 条泄漏探针 + 本模块不重算任何特征 |
| 缺失处理两种做法都写明并计数 | `RidgeForecaster.dropped_rows`、`LstmForecaster.dropped_rows`、`GbdtForecaster.dropped_rows == 0` | 见 §2.3 表 |
| 多随机种子 | `training.SEEDS = (20260921, 1, 2)` | 所有指标给 `均值 ± 标准差` |
| 评估指标口径 | 直接复用 `river_sentinel_ml.metrics.evaluate_forecasts` | `test_evaluate_predictions_matches_the_existing_metric_implementation` |
| 零样本兜底 | `training.evaluate_predictions` 返回 `sample_count=0` + 五项指标 `null` + `reason` | `test_zero_sample_fallback_is_null_with_a_reason`、`test_run_hourly_experiments_reports_a_zero_sample_segment` |
| 不以 test 调参 | `alpha` 与早停只看 validation；`test` 结果不回流 | `test_alpha_selection_returns_a_candidate_scored_on_validation` |
| 同种子两次运行一致 | 全流程无额外随机源 | 见 §9 实测（最大绝对差 **0.0**） |

> （DS-5b 已声明该差额），而 `usable_h{h}` 要求目标在同一段内。两个口径都自洽，但**不可混用**。

### 2.3 缺失特征导致的两个样本口径（必须区分）

DS-6 提示词要求线性/LSTM 剔除含 `NaN` 特征的行，树模型由 XGBoost 原生处理。本数据集的
validation / test 段缺失率高达 53.99% / 66.16%，段内滞后列因此大面积缺失，**两个口径的样本
量差距极大**：

| 实验 | horizon | 段 | `usable_h{h}` | 含缺失特征的行 | Ridge / LSTM 实际评估样本 | XGBoost 实际评估样本 |
| --- | --- | --- | --- | --- | --- | --- |
| E1/E2 | h1 | train | 1610 | 571 | **1039** | **1610** |
| E1/E2 | h1 | validation | 197 | 174 | **23** | **197** |
| E1/E2 | h1 | test | 144 | 130 | **14** | **144** |
| E1/E2 | h3 | train | 1518 | 532 | **986** | **1518** |
| E1/E2 | h3 | validation | 165 | 151 | **14** | **165** |
| E1/E2 | h3 | test | 118 | 110 | **8** | **118** |
| E1/E2 | h6 | train | 1401 | 466 | **935** | **1401** |
| E1/E2 | h6 | validation | 121 | 118 | **3** | **121** |
| E1/E2 | h6 | test | 84 | 82 | **2** | **84** |

**这是本轮最重要的方法学发现**：在"段内构造特征 + 剔除含缺失特征行"的组合下，线性与 LSTM
在 test 段只剩 **14 / 8 / 2** 个可评估样本（h1/h3/h6）。任何基于这 2~14 个样本的"超过持久性"
都是抽样噪声，**不得作为结论引用**。树模型因原生处理缺失而保留全部 144 / 118 / 84 个样本，
与持久性基线的样本集**完全一致**，因此只有 XGBoost 的对照是可比的。

该问题属协议级影响（不是实现缺陷），须由主 Agent 裁定后续处置（见 §10）。

1. **单一高水位过程的系统性失败**。XGBoost 三个 horizon 的最大绝对误差（1.10~1.24 m）全部

## 8. 必须随结论引用的声明

1. **HS-D-5 有界前瞻**：`resample_water_level` 在每小时桶内取**末次观测**、时间戳取**桶左边界**，
   因此行 `t` 的值可能包含 `t` 之后最多 1 小时内的读数，标签 `t` 可能晚于 `t` 至多一个桶宽。
   **1 小时 horizon 的评估结果偏乐观**，3 / 6 小时 horizon 不受该影响。本数据集**不得**被描述为
   严格因果序列之外的东西。
2. **test 段限制**：test 段 464 小时中缺失 **307** 小时（**66.16%**），`usable_h1/h3/h6` 仅
   **144 / 118 / 84**，属数据源缺失而非模型或切分缺陷。按 HS-D-15 修订后的门槛
   「任一 horizon 的 test 段 `usable_h{h}` < 80 即停止」逐项核验：144 ≥ 80、118 ≥ 80、84 ≥ 80，
   **门槛达标，未触发停止条件**。测试段指标只能作为探索性参考，**不得**用于任何超参、特征或
   模型选择。
3. **HS-D-12 结论保守性**：样本量有限（全量可用样本 1951 / 1801 / 1606），全部结论标注
   **探索性 / 教学科研**；**不给出正式洪水预警结论**，**不就高水位事件下确定性结论**，
   **不使用「超警」表述**。
4. **降雨口径（HS-D-9）**：E2 使用的降雨是 **Open-Meteo Best Match 网格化再分析**降雨，
   5 个网格点（`WC-G1`…`WC-G5`）**等权区域平均**，是「**文成县区域降雨代理变量**」；
   它**不是地面雨量站实测值**，也**不是 ERA5-Land**（实测 `models=era5_land` 在本区域全无有效值）。
   论文、页面与智能体回答一律按此口径表述。
5. **协议口径**：仅使用 `usable_h{h} = True` 的行（C-5 剔除目标时刻被插补的样本）；
   标准化、`alpha` 选择与早停只用 train / validation；test 段只在最终评估时读一次；
   每个 horizon 单独建模，禁止递归滚动；切分无 gap，窗口不跨段。

## 10. 已知限制与遗留问题

### 10.1 限制（必须随结论引用）

1. **样本口径不齐（本轮最重要）**：Ridge / LSTM 因剔除含缺失特征的行，test 段只剩
   14 / 8 / 2 个样本，无法与持久性和 XGBoost 公平比较（§2.3、§6）。
2. **模型全面未超过持久性**：仅 XGBoost 具备可比样本，且三个 horizon 全部落后（§5）。
3. **高水位过程是主要失效模式**：最大绝对误差集中在 2022-09-30 的单一上涨过程，且方向为低估。
4. **有界前瞻**使 1 小时 horizon 偏乐观（HS-D-5）。
5. **降雨是再分析代理变量**，且 E2 相对 E1 的差异在 test 段不一致（见 §10.3）。
6. **TCN 未实现**（提示词中为可选项）。
7. **目标断面坐标未核实**，降雨为县域区域代理变量，断面代表性有限。
8. Ridge 的 `alpha` 全部选中候选集下界 `0.1`，说明候选集未覆盖更优区间（若需要可扩到 `0.01`），
   但本轮不得以 test 结果回头调参。

### 10.2 对 DS-7 的交接

1. **最优配置（在可比样本上）**：`E2 + XGBoost`（test MAE 0.080296 / 0.208911 / 0.299731，
   略优于 E1 的 h1/h3，h6 相反），但**任何配置都没有超过持久性基线**，DS-7 必须以
   **持久性基线**作为参照系与对照模型。
2. **可用于误差分析与高水位事件的预测序列路径**（首种子 `20260921`，被忽略目录）：
   `data/processed/hourly_model_predictions/{E1,E2}/{ridge,xgboost,lstm}_h{1,3,6}_{train,validation,test}.csv`，
   列为 `observed_at`（anchor，`+08:00`）/ `segment` / `observed`（`target_h{h}`）/ `prediction`。
   模型权重与超参元数据在 `ml/artifacts/hourly-models/{E1,E2}/{model}/h{h}/seed20260921/`。
3. **E1 / E2 差异结论**：**没有稳健的降雨增益**。
   - test 段 XGBoost：h1 E2 优于 E1 0.0033（≈1.2σ），h3 优 0.0040（≈0.7σ），h6 **E1 优于 E2**
     0.0125（≈0.7σ）；
   - validation 段 XGBoost：E1 在三个 horizon 上都略优于 E2（0.093707 vs 0.094313、

5. **协议级问题待裁定**：线性 / LSTM 的 test 可用样本仅 2~14，是否改为「用训练段统计量填充
   缺失特征」（属 HS-D-8 允许范围但超出 DS-6 冻结协议），须由主 Agent 决定，本任务未擅自变更。

### 10.3 本轮未能解决的问题

- **未能得到一个超过持久性基线的模型**：受限于 144 / 118 / 84 个测试样本与 66.16% 的缺失率，

- **未能给出可信的 E1 / E2 差异结论**：需要更多有效样本或更长的目标序列。
- **未做超参搜索**：本轮只用了一套固定的、保守的 XGBoost / LSTM 配置，避免以 test 调参。
  `alpha` 候选集下界落在 `0.1`，建议后续在 validation 上扩大候选范围后重新实验。
