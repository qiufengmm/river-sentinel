# 数据源治理记录模板（候选数据集登记用）

> 使用说明：复制本文件为 `source-cata-<iid>.md`（或 `source-<平台给出的标识>.md`），逐节填写。
> 无法从平台页面确认的字段，一律写 **「待确认」**，禁止推测、禁止用别名替换平台字段名。
> 本文件只记录来源、字段口径、访问状态与校验值存放位置，**不记录任何凭据取值**。
> 本系统仅用于教学科研与辅助分析，不替代水行政主管部门的正式监测、预警、调度或应急决策。

- 快照为合法 JSON（NDJSON，非有限数值写 `null`）
- 实际获取时间：（未抓取写「未获取」，不得用样例数据冒充真实抓取）

## 8. 待确认项清单（凭据到位后逐项核实）

1. 字段字典逐字段含义与数据类型；
2. 接口路径与分页上限是否与水位源一致；
3. 测站编码/名称/经纬度是否存在，能否确认目标断面身份；
4. 真实更新频率与数据时间范围；
5. 许可条款是否允许用于论文实验。
