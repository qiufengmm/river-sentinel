字段字典（沿用平台官方字段名，本仓库不做重命名）：

| --- | --- | --- |
| `time_d` | 观测时间（平台原始时间文本） | 由 `normalize_water_level_rows` 解析并本地化到 `Asia/Shanghai`；不可解析、歧义或不存在的本地时间记为 `invalid_timestamp_rows` |

## 3. 分页与配额

- 单页上限：`200`（`MAX_PAGE_SIZE`），超过即由适配器拒绝，不做静默截断式请求。
- 迭代规则：按 `get_total.do` 声明的总数分页取数；单页返回超过剩余数量时截断，绝不产出超过平台声明数量的记录。
- 空页提前结束迭代。

## 5. 获取时间与校验值的存放位置

每次取数都会写不可变原始快照与相邻清单（快照写在当次运行的 run 目录内，run 目录自包含）：

- 快照：`<run 目录>/wenzhou/<dataset_id>/YYYY/MM/DD/<UTC时间戳>-<sha256前12位>.ndjson`
- 清单：同目录同名 `.manifest.json`，含 `source_name`、`source_uri`、`dataset_id`、`acquired_at`（获取时间，UTC）、`request_parameters`、`record_count`、`sha256`
- 快照为合法 JSON（NDJSON，非有限数值写 `null`），校验值即清单中的 `sha256`，可用 `sha256sum`/`Get-FileHash` 复核。
- 快照写入使用排他创建：已存在的快照绝不被覆盖；run 目录名唯一（时间戳 + 同秒序号），因此快照路径唯一、同一批数据重复运行不会撞名。
- 每次运行保留当次抓取的原始快照，**不做跨 run 去重**；长期运行需自行清理旧 run 目录。

## 6. 更新频率警示

### 9.1 两个下载入口的实际机制（页面证据）

- 详情页（<https://data.wenzhou.gov.cn/jdop_front/detail/data.do?iid=12720>，2026-09-21 访问，HTTP 200）「数据下载」按钮调用 JS `showKfxy(type,id)`，「历史数据下载」按钮调用 JS `showKfxyHistory(type,id)`。
- 两函数定义在 <https://data.wenzhou.gov.cn/jdop_front/resources/jdop/common/base.js>（2026-09-21 访问），分别打开开放协议对话框：`../channal/kfxy.do?type=<格式>&id=12720` 与 `../channal/kfxy_history.do?type=<格式>&id=12720&history=1`。
- 对话框页面内的下载函数 `download(type,id)`（原文）显示真实下载端点：
  - 数据下载：`window.location.href = '../resource/data/download.do?fileType='+type+'&iid='+id`
  - 历史数据下载：`window.location.href = '../resource/data/download.do?fileType='+type+'&iid='+id+'&history=1'`
- 结论：两组入口**唯一差别**是 `&history=1` 参数；页面上不存在年包、月包、分卷选择或其它下载入口。

### 9.3 结论：是否存在更多数据

**否（已穷举入口与格式，清单见 9.2）**。依据：

1. 页面上只有「数据下载」与「历史数据下载」两组入口，无年包/月包/分卷入口；
2. 「历史数据下载」实测只返回 10 条且为全量子集；
3. 「数据下载」5 种格式均返回同一规模 107105 条，与页面标注数据量一致；
4. CSV 本次 SHA-256 与 DS-1（2026-09-21T06:48:43Z）下载结果**完全相同**，说明返回内容确定、非随机截断。

因此：**107105 行 / 118 个有记录日 / 2022-06-02 ~ 2022-10-09 是该数据集本身的现有规模**，不是下载截断或解析遗漏。页面标注「时间范围：2022年至今」与实际末条 2022-10-09 不一致，**待确认**（不排除平台后续更新或不再更新）。
