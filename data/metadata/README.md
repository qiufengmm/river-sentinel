# 数据元数据（data/metadata）

> 本目录存放与原始数据配套的、可版本化的小型元数据文件（网格点、口径说明等）。
> 本系统仅用于教学科研与辅助分析，不替代水行政主管部门的正式监测、预警、调度或应急决策。

## 文成县固定降雨网格点（wencheng_grid_points.csv）

- 字段：`point_id,longitude,latitude,note,source,basis`（经度、纬度为 WGS-84 十进制度）。
- 行政边界来源：OpenStreetMap Nominatim（`https://nominatim.openstreetmap.org`，文成县 OSM relation 3289421，正向检索边界框 纬度 27.5661802 ~ 27.9904859、经度 119.7744702 ~ 120.2515184；访问日期 2026-09-21）。
- 每个网格点均经 Nominatim 逆向地理编码（`zoom=10`，访问日期 2026-09-21）逐一核实返回「文成县, 温州市, 浙江省, 325300, 中国」后方可登记；边界框内但逆向编码落在泰顺县、平阳县的候选点已被剔除（如 119.85/27.65、120.12/27.62），登记过程未使用目标断面坐标。
- 共 5 个固定网格点（WC-G1 ~ WC-G5），覆盖文成县中部、西北、东北、南部偏西与东南。
- **冻结规则**：网格点一经登记即冻结，后续不得为结果好看而调整；如需调整须在治理文档中单独记录理由与日期。
- **口径**：多点（算术）平均降雨在所有产物中标注为「**文成县区域降雨代理变量**」（网格化再分析，非地面雨量站实测，见 `docs/data-governance/source-open-meteo-era5land.md`）。
